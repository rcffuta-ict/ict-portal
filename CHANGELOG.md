# Changelog

Versioning follows this project's own rule, which is about the DATABASE:

- **PATCH** — code only. No migration; deploying does not touch the database.
- **MINOR** — a new migration exists. SQL must be applied.
- **MAJOR** — not safely reversible: dropped columns or tables, or a manual step.

Generated by `node scripts/release.mjs`.

## 1.0.0 — 2026-09-25

**The handover release.** The first tagged version, and the one the fellowship takes
over. Since the last deploy to production it adds:

- **Academics**: semester results collected through a round link, a 5-point analytics
  dashboard, managed departments, and an Academics tab in Workforce for unit heads.
- **Handover**: finishing the wizard schedules the switch for an hour later, with a
  countdown and a cancel. The switch now empties PDS/UABS, opens an empty 100 Level
  ("2028 Set"), renames PDS/UABS to the new session, and closes any open results round.
- **Tenure identity**: a tenure has no name (session, theme, theme text); coronation,
  banner and palette. `tenures.name` is dropped, which is why this is MAJOR.
- **Service history**: an appointment ends instead of being deleted.
- **Workforce**: switched on, with member details, birthdays and a membership log.
- **Test emails**: outside production only `@rcffuta.test` addresses are accepted.

- **Structure reset**: units, offices and access tags now match the catalogue exactly;
  offices and units from before it are removed. Both entry levels, PDS/UABS and
  100 Level, always exist.

Production already has the first five migrations listed below (the baseline and
0011–0013 and `20260920162209`); the other ten are new to it.
